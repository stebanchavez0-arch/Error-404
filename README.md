Problema 2: Directorio de rutas alternas y horarios de transporte interveredal

Contexto translocal: Varios Municipios enfrentan restricciones de movilidad hacia Bogotá por derrumbes en la vía, lo que afecta el acceso a salud y educación. Las comunidades rurales necesitan información clara sobre rutas alternas y horarios de transporte.

Delimitación para el reto:

- Crear una página web estática (HTML/CSS/JavaScript) que muestre un directorio de rutas de transporte (interveredal o intermunicipal) con: nombre de la ruta, horario de salida y punto de encuentro.

- La información debe ser administrable mediante un archivo JSON que el equipo precargue con datos de ejemplo (no se requiere panel de administración).

- La interfaz debe ser responsive, con navegación por pestañas o filtros simples por municipio o vereda.

- No se requiere geolocalización en tiempo real ni mapas interactivos; el valor está en la claridad y accesibilidad de la información.

La aplicación debe estar desarrollada únicamente con HTML5, CSS3 y JavaScript vainilla (sin frameworks externos complejos).
